# VOCALOID Patcher

[<img src="./res/lang_zh.svg" alt="阅读中文版" height="28">](./README.MD)
[<img src="./res/lang_en.svg" alt="Read this in English" height="28">](./README_EN.MD)

`VOCALOID 6` エディターに追加機能を提供するパッチです。理論上はすべてのバージョンの V6 エディターに対応しています。

### 翻訳エントリバージョン: `6.13.0.1`
### 動作確認済みエディターバージョン: `6.1.0.2 (.net 6.0)`, `6.6.0`, `6.11.0.1`, `6.12.0.1`, `6.13.0.1`

私自身は V6 エディターの使用経験があまり多くないため、翻訳が正確でない場合があります。Issue を立てるかグループで知らせていただければ、次のバージョンで修正します。

## インストール
[Releases](https://github.com/IzumiiKonata/VOCALOIDPatcher/releases) から最新版をダウンロードしてください。  
エディターのバージョンが古い場合は `.net 6.0` 向けのビルドをダウンロードしてください。  
アーカイブ内のすべてのファイル _(README.txt を除く)_ を `C:\Program Files\VOCALOID6\Editor` にコピーして上書きします (エディターが既定のディレクトリ以外にインストールされている場合は正しく動作しないことがあります)。  
エディターを起動してプロジェクトを開き、メニューバーに `VOCALOID Patcher` の項目が表示されればインストール成功です。  
![img](./res/screenshot.png)

## 機能

### ローカライズ / 多言語
- エディターのリソースエントリとハードコードされた文字列の両方を翻訳します。翻訳ファイルは外部 XML なので、自分で編集できます。

### ピアノロール拡張
- **他トラックのノートを表示**: 現在のトラックのピアノロールに他トラックのノートを重ねて表示します。ミュート中のトラックをスキップするオプションもあります。  
![Show Other Notes](./res/show_other_notes.png)
- **ノートの音高を表示**: 各ノートに音名 (例: `C4`, `F#3`) を重ねて表示します。  
![Show Note Pitch](./res/show_note_pitch.png)
- **角丸ノート**: ノートの形状を角丸の矩形に変更します。  
![Rounded Notes](./res/rounded_notes.png)
- **歌詞を中央揃え**: 歌詞を垂直方向に中央揃えします。  
![Centered Notes](./res/centered_notes_b.png)
- **常に波形を表示**  
![Always Show Wave](./res/always_show_wave.png)
- **ボイスバンクのカバー表示 / カスタム立ち絵**: 現在のパートで使用しているボイスバンクのカバーをピアノロール右下に表示します。サイズと不透明度を調整できます。
  - **ボイスバンクごと**にカスタム立ち絵を 1 枚アップロードして既定のカバーを置き換えられます。パートのボイスバンクを切り替えると自動的に更新されます。
  - 立ち絵は静止画像のほか、`GIF` アニメーションや `MP4` などの動画 (ループ再生・ミュート) にも対応しています。追加の依存関係は不要です。
  - 立ち絵はノートの下のレイヤーに描画されるため、ノートを隠しません。

### ウィジェット
- **スペクトラム表示**: エディター内にリアルタイムのオーディオスペクトラムを表示します (ASIO 使用時は正しく動作しません)。

### ジョブ
- **歌詞の置換**: 選択したノートの歌詞を指定した音節で一括置換します。
- **音価のクォンタイズ**: ノートの長さをグリッドにクォンタイズします。
- **ハモリ生成**: スケールのルート音を基準に、上下の 3 度・4 度・5 度・6 度・オクターブなど複数の声部を生成します。既存トラックにも新規トラックにも書き込めます。
- **スウィンググルーヴ**: ピアノロールの右クリックメニューに 8 分 / 16 分のスウィングおよびシャッフルのプリセットを内蔵しています。

### 複数フォーマットのインポート / エクスポート
- ネイティブの `Vpr/Vsqx/MIDI` に加えて、以下のプロジェクトフォーマットとの相互変換 (インポート + エクスポート) に対応しています:
  `USTX` (OpenUTAU)、`UST` (UTAU)、`SVP` (Synthesizer V Studio)、`S5P` (Synthesizer V Editor)、`VSQ` (VOCALOID2)、`CCS` (CeVIO)、`Tssln` (VoiSona)、`ACEP` (ACE Studio)、`VVProj` (VOICEVOX)、`PPSF` (Piapro Studio NT)、`DV` (DeepVocal)、`TLPX` / `TLP` (TuneLab)、`SVIP` (X Studio)、`DS` (DiffSinger)、`AISP` (AISingers)、`Y77` (Yuan77)、`VOG` (Vogen)、`MusicXML`、`OpenSVIP` (json)、`ufdata` (UtaFormatix)。
- さらに歌詞 / 字幕のエクスポートにも対応しています: `LRC`、`SRT`、`ASS`。
- インポート / エクスポート時には、ピッチカーブや音素などのデータを対象フォーマットに合わせて自動的に変換します。

### パフォーマンスと滑らかさ
- **プロジェクト読み込みを高速化**: オーディオ波形の先読みや読み込み時の統計収集など、後回しにできる処理をクリティカルパスから外し、大きなプロジェクトを速く開けるようにします。
- **メモリ最適化**: 読み込み・レンダリング後に不要になったオーディオキャッシュを解放し、ワーキングセットを切り詰めます。
- **トラックエリアの描画を最適化**: トラック / ノートのブラシなど再利用できるオブジェクトをキャッシュし、トラックエディターの再描画コストを抑えます。
- **パート切り替えを高速化**: 同じトラック内でパートを切り替える際、変化しない部分の再描画をスキップして切り替えをスムーズにします。
- **合成波形キャッシュ**: パート切り替え時に読み込み済みの合成波形を再利用し、毎回 UI スレッドでディスクから読み直すのを防ぎます。
- **選択解除を高速化**: 実際に選択されていたイベントだけを解除し、クリックごとにプロジェクト全体をスキャンしないようにします。
- **パラメータパネルの遅延更新**: トラック / パートの切り替え時に下部のパラメータパネルを少し遅れて更新し、切り替えの反応を即座にします。
- **再生位置ラインをスムーズに**: ピアノロールの白い再生位置ラインを、バックグラウンドタイマーではなく画面の更新周期で動かし、不規則なカクつきを解消します。スペクトル表示中は特に効果的です。

### その他
- **自動保存**: 設定した間隔で現在のプロジェクトを自動保存します。
- **タッチパッドでの横スクロール**: タッチパッドでピアノロールを左右にスクロールできるようにします。

## デバッグ
パッチをインストールした後、`VOCALOID 6` エディターを起動する際に `左 Shift` を長押しするとコンソールが表示され、`VOCALOIDPatcher` がそこにデバッグログを出力します。

## 翻訳の更新
`ResourceTranslationComparer` を実行すると、コンソールに翻訳の比較結果が出力されます:

- **[1] 未翻訳エントリ**: 新しく追加された resx 翻訳エントリ。
- **[2] 未翻訳かつ未使用のエントリ**: どの UI 要素からも参照されていない resx エントリ。
- **[3] ハードコードされた文字列**: `HardcodedPropertyMap.xml` に追加します (リテラル → カスタムキー)。
- **[4] 余分なキー / [5] 未使用のハードコード文字列**

`--write-map` 引数を渡すと、整理済みの `HardcodedPropertyMap.generated.xml` を追加で出力します。

## 開発

### 注意事項
既定のディレクトリ `(C:\Program Files\VOCALOID6\Editor)` に最新の VOCALOID6 エディターをインストールしておく必要があります。  
ビルド後、依存関係を同梱した `Microsoft.Xaml.Behaviors.dll` が `VOCALOIDPatcher\bin\Release\net8.0-windows\out` に生成されます。  
`mklink` コマンドでビルド済みの dll をエディターのディレクトリにシンボリックリンクすると、ビルドのたびに手動で上書きする手間を省けます。
